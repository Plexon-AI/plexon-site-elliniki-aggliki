Η φωνή που θα λέει την ελληνική μετάφραση πριν από κάθε αγγλική φράση.
Δεν βρέθηκε ελληνική φωνή
Χωρίς ελληνική φωνή το κουμπί δεν μπορεί να λειτουργήσει, γιατί δεν θα υπήρχε φωνή να μιλήσει τα ελληνικά. Εγκατέστησε μία:
  1. Windows: Ρυθμίσεις → Ώρα και γλώσσα → Γλώσσα και περιοχή → πρόσθεσε «Ελληνικά» και επιλέξε «Φωνή».
  2. Android: Ρυθμίσεις → Σύστημα → Γλώσσες και είσοδος → Μετατροπή κειμένου σε ομιλία → εγκατέστησε την ελληνική φωνή.
  3. iPhone και iPad: Ρυθμίσεις → Προσβασιμότητα → Περιεχόμενο προφορικό → Φωνές → Ελληνικά.
  4. Edge: Ρυθμίσεις → Ομιλούμενες γλώσσες → πρόσθεσε τα Ελληνικά.
Όταν είναι ενεργό, κάθε αγγλική φράση ακούγεται δύο φορές: πρώτα στα ελληνικά, μετά στα αγγλικά.
